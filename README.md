# RP Chat

- `index.html` + `app.js` — весь сайт, без сборки и зависимостей
- Персонажи и переписка хранятся в **localStorage браузера**, на сервер ничего не уходит
- Запросы идут напрямую в RouterAI (`https://routerai.ru/api/v1`), API-ключ вводится в настройках и лежит только у тебя в браузере
- В настройках есть выгрузка/загрузка JSON — чтобы перенести персонажей между устройствами

Открыть: https://doty-amoeba.github.io/rp-chat/
